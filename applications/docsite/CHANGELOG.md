# Changelog

Notable changes to this application are recorded here, one section per release.
A description says what it is and does not change between releases; this says
what changed.

## [0.1.0] - 2026-10-12

Initial release: a Rho application that serves the documentation tree as a site —
an index with an overview and the project's release notes, a menu beside every
page, and the pages rendered with the documentation generator through the new
`docstore` port.
